# dynatrace_segments (Data Source)

-> **Dynatrace SaaS only**

-> This data source requires the OAuth permission **View Filter-Segments** (`storage:filter-segments:read`)

The `dynatrace_segments` data source lists the ID and name of all segments. Ready-made segments are not returned.

## Dynatrace Documentation

- Segments - https://docs.dynatrace.com/docs/manage/segments

## Example Usage

```terraform
data "dynatrace_segments" "all" {}

output "segment_names" {
  value = data.dynatrace_segments.all.values[*].name
}
```
