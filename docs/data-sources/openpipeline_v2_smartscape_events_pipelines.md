# dynatrace_openpipeline_v2_smartscape_events_pipelines (Data Source)

-> This data source requires the OAuth scope `settings:objects:read`.

The `dynatrace_openpipeline_v2_smartscape_events_pipelines` data source retrieves all matching smartscape events pipeline configurations.

## Dynatrace Documentation

- OpenPipeline - https://docs.dynatrace.com/docs/platform/openpipeline

## Example Usage

```terraform
data "dynatrace_openpipeline_v2_smartscape_events_pipelines" "pipelines" {
  display_name = dynatrace_openpipeline_v2_smartscape_events_pipelines.pipeline.display_name
  group_role   = "memberPipeline"
}

resource "dynatrace_openpipeline_v2_smartscape_events_pipelines" "pipeline" {
  display_name = "#name#"
  custom_id    = "pipeline_Minimal_pipeline_1234_tf_#name#"
  group_role   = "memberPipeline"
```
