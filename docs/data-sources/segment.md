# dynatrace_segment (Data Source)

-> **Dynatrace SaaS only**

-> This data source requires the OAuth permission **View Filter-Segments** (`storage:filter-segments:read`)

The `dynatrace_segment` data source allows to get a segment and all its data by its name or by its ID (the `uid` generated by Dynatrace on creation). Exactly one of `name` or `id` must be set. Ready-made segments are not found by `name`. Because the `name` of a segment isn't unique, the first match is returned if the segment is looked up by `name`.

## Dynatrace Documentation

- Segments - https://docs.dynatrace.com/docs/manage/segments

## Example Usage

```terraform
data "dynatrace_segment" "example" {
  name = "Terraform"
}

output "id" {
  value = data.dynatrace_segment.example.id
}

data "dynatrace_segment" "by_id" {
  id = "GQ7NqJGPV1N"
}
```
